# Local Project Paths

Copy this file to `projects/local-paths.md`.

The copied file is gitignored because paths differ across machines.

Prefer relative paths when the memory workspace and projects share an outer folder.

```text
- `customer-portal`: `../customer-portal`
- `automation-service`: `/Users/name/code/automation-service`
- `windows-project`: `C:\Users\Name\code\windows-project`
```
